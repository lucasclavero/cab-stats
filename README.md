# CABB Stats

App local para recortar planillas oficiales de la CABB (XLS/XLSX o PDF) y ver estadísticas de equipo, top 5 por rubro y el desglose de un jugador.

## Cómo verla

```bash
npm install
npm run dev
```

Abre http://localhost:5173 y subí una o más planillas `estadisticaPartido_*.xlsx` / `.pdf`.

El equipo se elige solo (el que más aparece). Si hay varios, usá el selector arriba a la derecha.
